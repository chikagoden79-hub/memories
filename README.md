# Воспоминания — сайт + телеграм-бот

## 1. Деплой на Netlify

1. Залей эту папку в новый репозиторий на GitHub.
2. На netlify.com → **Add new site → Import an existing project** → выбери репозиторий.
3. Build command: `npm install`, Publish directory: `public` (уже прописано в `netlify.toml`, можно просто нажать Deploy).
4. После деплоя сайт будет на `https://ТВОЁ-ИМЯ.netlify.app`. Netlify Blobs (хранилище фото) включится автоматически, ничего отдельно настраивать не надо.

## 2. Телеграм-бот

1. Напиши **@BotFather** в Телеграме → `/newbot` → задай имя → получишь токен вида `123456:AAExxx`.
2. В Netlify: Site settings → Environment variables → добавь `TELEGRAM_BOT_TOKEN` = твой токен → передеплой сайта (Deploys → Trigger deploy).
3. Подключи вебхук (выполни один раз, например в браузере или через curl), подставив свой токен и адрес сайта:

```
https://api.telegram.org/bot ТВОЙ_ТОКЕН/setWebhook?url=https://ТВОЁ-ИМЯ.netlify.app/api/telegram-webhook
```

4. Готово. Теперь просто отправь боту фото:
   - Без подписи → сохранится с сегодняшней датой.
   - С подписью, начинающейся с даты — `21.07.2026 гуляли в парке` или `2026-07-21 гуляли в парке` — сохранится с этой датой, а остальной текст станет подписью.
   - Бот ответит "Сохранено ✅" — и фото сразу появится на сайте у всех, кто его откроет.

## Как это устроено

- `public/index.html` — сам сайт (Галерея / Добавить / Случайное воспоминание).
- `netlify/functions/memories.js` — API для списка и добавления/удаления воспоминаний.
- `netlify/functions/image.js` — отдаёт сами фото по id.
- `netlify/functions/telegram-webhook.js` — принимает фото от бота и кладёт их в то же хранилище, что и сайт.

Всё хранится в Netlify Blobs — это общее хранилище для сайта, доступное с любого устройства, без сторонних сервисов.
